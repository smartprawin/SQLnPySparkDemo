🌀 Airflow Golden Questionnaire July 2026 • 6 Questions

Airflow Interview Q&A

6 Questions — DAGs, XCom, triggers, retries, dependencies, Step Functions

Source: GOLDEN_QUESTIONNAIRE_JULY_2026.pdf • Each card = interview-ready answer. Use bookmarks + Mark as Complete to track prep.

🟡 Intermediate

Q1. DAG? How it works?

Interview Answer: Directed Acyclic Graph = ordered workflow of tasks. Dependencies set order. Airflow schedules, executes, monitors. I use DAGs for ETL.

🟡 Intermediate

Q2. XCom? xcom_push/pull?

Interview Answer: Cross-task small-data sharing. push stores, pull retrieves. I pass filenames/IDs/status.

Code 
ti.xcom_push(key="file_name", value="sales.csv")
file = ti.xcom_pull(key="file_name")
🟡 Intermediate

Q3. Ways to trigger a DAG?

Interview Answer: Schedule (cron), manual UI, CLI, REST API, TriggerDagRunOperator from another DAG.

🟡 Intermediate

Q4. Task retries?

Interview Answer: Auto-retry per retries + retry_delay config. After exhausting, marked failed + alerts.

Code 
default_args={'retries':3,'retry_delay':timedelta(minutes=5)}
🟡 Intermediate

Q5. Airflow vs Step Functions?

Interview Answer: Airflow = ETL scheduling/orchestration. Step Functions = coordinate AWS services (Lambda/Glue/ECS) serverless. Complex data→Airflow, AWS events→SFN.

🟡 Intermediate

Q6. Define dependencies?

Interview Answer: >> / << or set_upstream/downstream. Ensures order: extract → transform → load.

Code 
task1 >> task2 >> task3
